# HaloDrops website

A fast, responsive static marketing and support website for HaloDrops for Mac.

- Marketing: https://mehraabsingh.github.io/web-halodrops/
- Support: https://mehraabsingh.github.io/web-halodrops/support/

## Local preview

Run `python3 -m http.server 4173` in this folder, then open http://localhost:4173/.

## Hosting

GitHub Pages publishes from the root of the `main` branch. `.nojekyll` keeps the site buildless. No third-party scripts, analytics, cookies, or package dependencies are used by the website.

Images are captures of the running HaloDrops app. The landscape inside the app is original generated demo content.
