FIRST THINGS FIRST

Up and running.

  1. Open HaloDrops.

    Look for the HaloDrops icon in the macOS menu bar. The app lives there, so you don’t need to keep a main window open.

  2. Choose a file.

    Drag a file in Finder while holding ⇧ Shift. Release it over a format on the conversion wheel. You can also click the menu bar icon and choose Convert Files….

  3. Explore the tools.

    Hold ⇧ Shift + ⌥ Option while dragging, or choose Open Tool for Files… from the menu. Tools vary with the selected file type.

  4. Find your result.

    By default, output is saved next to the original. Change the destination in Settings → General → Output.

GOOD TO KNOW

Common questions.

Where is the main HaloDrops window?

HaloDrops is a menu bar utility. Click its icon at the top of your screen to convert files, open a tool, or access Settings. Editing windows appear when you choose a tool.

Which formats can I convert?

The wheel shows compatible output formats for the selected file. Image options can include JPG, WebP, HEIC, TIFF, AVIF, BMP, and PDF. The available options depend on the input type and installed media support. Select one file first if a mixed selection has no shared conversion.

Can I work with multiple files?

Yes. Select multiple files in Finder or in the file picker. HaloDrops shows compatible actions for the selection. Batch compression, image resizing, and PDF tools can help with groups of files.

Will editing or compressing replace my original?

Photo tools use Save copy, and compression creates compressed copies. Keep your original and use the new output for your next step. Check the destination shown in the app before saving.

Are my files uploaded for conversion?

Conversions and edits are performed locally on your Mac. HaloDrops does not require uploading your files to a conversion website. The app can make network requests to check for software updates.

Why does a tool mention FFmpeg?

Some advanced media operations require FFmpeg. If a tool displays this requirement, configure a compatible FFmpeg executable in HaloDrops Settings. Basic tools that use built-in macOS support do not all share this requirement.

How do I switch the appearance?

Open Settings → Appearance from the menu bar. Choose your preferred appearance and progress display style.

LET’S SORT IT OUT

A few quick fixes.

The wheel isn’t appearing.

Make sure HaloDrops is running, start dragging an actual file in Finder, and hold Shift. Check that the source app isn’t excluded in HaloDrops Settings. Try Convert Files… from the menu bar to use the file picker instead.

A file won’t convert or save.

Try one file at a time. Make sure it opens normally in its original app, the output folder is writable, and your Mac has enough available storage. Some formats and advanced operations need additional media support; check the message shown in the tool.

A PDF isn’t opening correctly.

Confirm the PDF opens in Preview. Password protection or a damaged document can prevent an operation. Try an unlocked copy that you have permission to edit.

I can’t find the output.

Check next to the original file, then review Settings → General → Output. Files may be saved to Downloads if that destination is selected. Look for the new file’s operation suffix, such as “edited” or “compressed.”

CONTACT THE DEVELOPER

Still need a hand?

Send a support request through GitHub Issues. You’ll need a GitHub account to submit a request and follow replies from the developer.

Open a support request ↗

Help us understand the problem.

  • Your macOS and HaloDrops versions.
  • The file type and tool you were using.
  • What you expected, what happened, and the exact error message.
  • Steps to reproduce the issue, if possible.

GitHub issues are public. Don’t attach private files, credentials, or unredacted logs. If useful, HaloDrops provides Show Logs in its menu; review and redact the contents before sharing.
